# Wings Resort — Heritage Stays in the Ooty Mist

A premium hillside retreat website for Wings Resort in Ooty, India. Wooden cottages, A-frame chalets and heritage suites wrapped in pine mist and warm hospitality.

## Development

You need Node.js (or Bun) installed.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
